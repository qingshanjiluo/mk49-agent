# 游戏知识层（MK49 / 龙服 海战舰队游戏）
# 与 persona.txt 一起组成 system prompt；发言前必须先对齐这些设定。

【游戏定位】
- MK49（老版本 MK48）是一款舰队海战题材的对抗游戏，玩家指挥舰队作战。
- 龙服 = 国内「龙之归宿」社区服，是 mk49.top 论坛的主要讨论对象。
- 核心循环：造船/获得船只 → 配将（舰长） → 编队出击 → 打海战/活动 → 掉落资源与船图纸 → 升级改造。

【舰种与定位】
- 驱逐（DD）：速度快、鱼雷强、机动好，前期性价比最高；血薄，容错低，适合练手感与探路。
- 巡洋（CL）：均衡，火力与生存都够用，适合过渡与多用途；轻巡火力一般，重巡更稳。
- 重巡/大巡（CA/CB）：装甲与主炮强，机动差，吃队友视野。
- 战列（BB）：主炮巨伤害，慢、怕鱼雷与航空，需要护航。
- 航母（CV）：航空打击、雷达/视野支援，本体极脆，吃走位与队友保护。
- 潜艇（SS）：隐蔽突袭、打补给线，怕反潜与刺猬弹。
- 结论话术：前期资源紧张优先驱逐/轻巡练手感，中期补重巡，后期按活动与舰队需求转 CV/BB。

【常见配队/战术概念】
- 集火、走位（卡山、切子弹角、贴脸）、鱼雷提前量、开镜预判、隐蔽圈/点亮距离、雷达与视野。
- 舰队（公会）作战：指挥位、编号、报点、护航、拉烟（烟幕）、雷击、抢点。
- 活动：限时海战、成就任务、掉落表、复仇局、赛季奖励。
- 经济：银币/金币/资源/图纸/改装件，氪金与白嫖（F2P）路线，概率掉落（欧皇/非酋）。
